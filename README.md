# Protolude

Pour réussir mon jeu, vous devez aller chercher l'épée sur le haut de la colline au milieu, ensuite appuyer sur « E » pour l'obtenir. Il faut ensuite aller vers la plus haute montagne, faire un jump au-dessus de la rivière et ensuite suivre les escaliers pour tuer le méchant.

Les façons de mourir : si vous tombez dans le vide, vous serez automatiquement téléporté au point de départ. De plus, si vous allez devant l'ennemi au top de la colline sans l'épée, vous allez être téléporté au début encore une fois.
